## 一、核心概念

知识蒸馏最早由 Hinton 等人在 2015 年的论文 *Distilling the Knowledge in a Neural Network* 中系统提出。其核心直觉是：

> 一个已经训练好的大模型（Teacher）不仅知道"正确答案是猫"，还知道"猫比狗更像狮子一点"——后者就是 **暗知识（Dark Knowledge）**，藏在 softmax 输出的概率分布里。

### 1.1 角色定义

| 角色              | 说明                            | 特点                                |
| ----------------- | ------------------------------- | ----------------------------------- |
| **Teacher** | 预训练好的大模型（或 Ensemble） | 参数量大、推理慢、效果好            |
| **Student** | 待训练的小模型                  | 参数量小、推理快、需要 Teacher 指导 |
| **温度 T**  | 控制 softmax 输出分布的平滑度   | 高温 → 分布平滑 → 暗知识更明显    |

### 1.2 核心流程图

```Python
┌─────────────────────────────────────────────────────────────┐
│                    知识蒸馏完整流程                            │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  ┌──────────┐         ┌──────────────┐                      │
│  │ 数据集    │         │ Teacher 模型  │ (已训练，冻结权重)    │
│  │ (无标签)  │──┬──────┤ (Large NN)   │                      │
│  └──────────┘  │      └──────┬───────┘                      │
│                 │             │                               │

```

## 二、数学原理

### 2.1 标准 Softmax

对于一个分类任务，标准 softmax 将 logits $z_i$ 转换为概率：

$$
p_i = \frac{\exp(z_i)}{\sum_{j} \exp(z_j)}
$$

这种输出是"硬"的——正确类别的概率接近 1，其他接近 0。

### 2.2 带温度的 Softmax

引入温度参数 $T$ 来软化分布：

$$
p_i^{(T)} = \frac{\exp(z_i / T)}{\sum_{j} \exp(z_j / T)}
$$

- **$T = 1$**：退化为标准 softmax
- **$T > 1$**：概率分布更平滑，类别间相对关系保留更完整
- **$T \to \infty$**：所有类别概率趋同
- **$T \to 0$**：退化为 one-hot（argmax）

### 2.3 温度对概率分布的影响

```
概率分布示意（3 分类：猫/狗/狮子）：

T=1 (标准softmax)：
  ┌────┐ ┌──┐ ┌──┐
  │猫  │ │狗│ │狮│
  │0.90│ │07│ │03│
  └────┘ └──┘ └──┘
  暗知识：几乎丢失

T=5 （高温）：
  ┌────┐ ┌────┐ ┌────┐
  │猫  │ │狗  │ │狮  │
  │0.45│ │0.30│ │0.25│
  └────┘ └────┘ └────┘
  暗知识："猫比狗更像狮子"
  关系完整保留

T=2 （适中）：
  ┌────┐ ┌────┐ ┌───┐
  │猫  │ │狗  │ │狮 │
  │0.70│ │0.18│ │0.12│
  └────┘ └────┘ └───┘
  强弱关系保留，但不失区分度
```

### 2.4 暗知识的信息价值

为什么要有暗知识？考虑下面这个场景：

```
真实标签：        [1, 0, 0]     ← '这是猫'

Teacher 输出（T=1）： [0.90, 0.07, 0.03]
Teacher 输出（T=5）： [0.45, 0.30, 0.25]
                           ↑      ↑
                     '比狮子更接近狗'  ← 暗知识

Student 如果只看真实标签：
  它只知道"输入 → 猫"，不知道猫和狗/狮子的关系

Student 如果学 Teacher 的分布：
  它学到"输入 → 猫（但狗也有点像，狮子不太像）"
  这相当于学到了 Teacher 的泛化能力
```

## 三、完整训练流程

### 3.1 阶段一：训练 Teacher

```
┌─────────────────────────────────────┐
│        训练 Teacher 模型              │
├─────────────────────────────────────┤
│                                     │
│  数据集 ──→ 大模型 ──→ 交叉熵损失 ──→ 反向传播         │
│  (有标签)      (ResNet-152 /          │
│                ViT-Large 等)          │
│                                      │
│  训练完成后：冻结 Teacher 权重         │
│  保存 Teacher 对所有样本的 soft target │
│                                      │
└─────────────────────────────────────┘
```

### 3.2 阶段二：蒸馏训练

```
┌──────────────────────────────────────────┐
│              蒸馏训练流程                   │
├──────────────────────────────────────────┤
│                                          │
│  输入 x                                  │
│    │                                     │
│    ├──→ Teacher（冻结）                    │
│    │      └──→ logits_t ──→ softmax(T) ──→ Soft Target  │
│    │                                     │
│    └──→ Student（训练中）                  │
│           └──→ logits_s ──→ softmax(T) ──→ Soft Prediction │
│                                          │
│  损失计算：                                │
│    L_KD  = KL_div(Soft_Target ∥ Soft_Pred)  ← 蒸馏损失    │
│    L_CE  = CrossEntropy(logits_s, y)        ← 真实标签损失  │
│    L     = α · T² · L_KD + (1-α) · L_CE     ← 总损失      │
│                                          │
│  反向传播 → 更新 Student 参数              │
│                                          │
└──────────────────────────────────────────┘
```

> **注意**：$L_{KD}$ 前乘 $T^2$ 是为了平衡梯度尺度。当 $T > 1$ 时，softmax 输出的梯度幅度会缩小约 $1/T^2$，乘以 $T^2$ 恢复其尺度，使超参数 $\alpha$ 在不同 $T$ 下的含义保持一致。

### 3.3 阶段三：Student 部署

```
训练结束后的部署流程：

Teacher 模型（大）                      Student 模型（小）
   ResNet-152 (60M)     ──→ 蒸馏 ──→    MobileNetV3 (5.4M)
   推理延迟：~50ms                       推理延迟：~5ms
   参数量：60M                           参数量：5.4M
   精度：95.2%                           精度：94.1%（蒸馏前 92.3%）

   ↑ 可以丢弃了                           ↑ 部署到生产环境
```

## 四、蒸馏损失函数详解

### 4.1 KL 散度（Kullback–Leibler Divergence）

蒸馏损失使用 KL 散度衡量 Teacher 和 Student 的概率分布差异：

$$
D_{KL}(P_t || P_s) = \sum_{i} p_t^{(i)} \log \frac{p_t^{(i)}}{p_s^{(i)}}
$$

其中 $p_t$ 是 Teacher 的 softmax 输出（$T$ 温度下），$p_s$ 是 Student 的 softmax 输出（同一 $T$ 温度下）。

性质：

- $D_{KL} \geq 0$，当且仅当两分布完全相同时取 0
- 非对称：$D_{KL}(P_t || P_s) \neq D_{KL}(P_s || P_t)$
- 蒸馏中固定 Teacher 为 $P_t$，优化 Student 使 $P_s$ 靠近 $P_t$

### 4.2 总损失函数

$$
\mathcal{L} = \alpha \cdot T^2 \cdot \mathcal{L}_{KD} + (1 - \alpha) \cdot \mathcal{L}_{CE}
$$

| 符号                 | 含义                                                                 | 典型值  |
| -------------------- | -------------------------------------------------------------------- | ------- |
| $\mathcal{L}_{KD}$ | $D_{KL}(P_t^{(T)} \parallel P_s^{(T)})$ --- Teacher 软标签蒸馏损失 | -       |
| $\mathcal{L}_{CE}$ | CrossEntropy(logits_s, y) --- 真实标签硬损失                         | -       |
| $\alpha$           | 蒸馏损失权重                                                         | 0.5~0.9 |
| $T$                | 温度参数（训练时）                                                   | 2~20    |
| $T^2$              | 梯度尺度补偿因子                                                     | $T^2$ |

### 4.3 梯度分析

为什么 Teacher 蒸馏比直接训练 Student 更好？从梯度角度看：

对于标准交叉熵训练，相对于 logits $z_s^{(i)}$ 的梯度为：

$$
\frac{\partial \mathcal{L}_{CE}}{\partial z_s^{(i)}} = p_s^{(i)} - \mathbb{1}(i = y)
$$

对于蒸馏损失，梯度为：

$$
\frac{\partial \mathcal{L}_{KD}}{\partial z_s^{(i)}} = \frac{1}{T} \left( p_s^{(i)}(T) - p_t^{(i)}(T) \right)
$$

**关键差异**：

- CE 梯度中，只有正确类别的梯度信息丰富，其他类别梯度极小
- KD 梯度中，**所有类别**都有非零梯度，因为 Teacher 在每一类上都提供了软概率
- 高温下，负类别的相对关系也被编码进梯度，Student 学到了类间相似性

### 5.1 分类体系总览

```
        │                  │                  │

   DarkRank (2017)   AT (2017)          IRG (2019)

```

```
                           知识蒸馏
                              │
              ┌───────────────┴───────────────┐
              │                               │
        离线蒸馏                          在线蒸馏
     Teacher 预训练固定                    Teacher & Student
     Student 单独训练                      同时训练
              │                               │
        ┌─────┴─────┐                   ┌─────┴─────┐
        │           │                   │           │
   标准蒸馏     自蒸馏                 互学习      对抗蒸馏
   Hinton 2015  Tf-Distil               Deep Mutual  VKD
               (student 自己当 teacher)   Learning
```

### 5.2 离线蒸馏（Offline Distillation）

最经典的形式。Teacher 提前训好并冻结。

```
训练流程：

阶段1：   数据集 ──→ 训练 Teacher ──→ 保存 Teacher 权重
阶段2：   Teacher(冻结) ──→ 生成 Soft Labels ──→ 训练 Student
阶段3：   部署 Student
```

**优点**：简单、稳定、Teacher 只需推理
**缺点**：Teacher 能力固定，无法随 Student 提升而调整

### 5.3 在线蒸馏（Online Distillation）

Teacher 和 Student 同时训练，可以是两个同等规模的模型互学习。

```
训练流程（互学习 Mutual Learning）：

输入 x
  ├──→ Model A ──→ logits_a ──→ 损失 L_A
  ├──→ Model B ──→ logits_b ──→ 损失 L_B
  │
  两个模型互相作为"Teacher"：
  L_A = CE(A, y) + KL(A_soft ∥ B_soft)
  L_B = CE(B, y) + KL(B_soft ∥ A_soft)
```

### 5.4 自蒸馏（Self-Distillation）

Student 自己当自己的 Teacher——用早期训练时期的版本指导后期训练。

```
自蒸馏流程：

Epoch 1:   Student ──→ 保存快照 Teacher_epoch1
Epoch 2:   Student ──→ KD(Teacher_epoch1, Student)
Epoch 3:   Student ──→ KD(Teacher_epoch2, Student)
...
Epoch N:   Student ──→ 最终模型
```

或者在每个 epoch 维护一个 **EMA（指数移动平均）** 版本的 Teacher：

```python
teacher_params = 0.999 * teacher_params + 0.001 * student_params
```

**优势**：不需要大模型，学生靠自己也能提升
**代表工作**：Born-Again Networks (Furlanello, 2018)

### 5.5 特征蒸馏（Feature-based Distillation）

不仅蒸馏最后的 logits，还蒸馏中间层的特征图。

```
特征蒸馏结构：

输入 x
  │
  ├──→ Teacher Backbone
  │       │
  │       ├──→ Layer_1_out ──→ ┐
  │       ├──→ Layer_2_out ──→ ├──→ ... ──→ Logits
  │       ├──→ Layer_3_out ──→ ┘
  │       │
  └──→ Student Backbone
          │
          ├──→ Layer_1_out ──→ ┐  ← MSE/余弦损失对齐中间特征
          ├──→ Layer_2_out ──→ ├──→ ... ──→ Logits
          ├──→ Layer_3_out ──→ ┘
```

**代表性方法**：

| 方法                       | 年份 | 核心思想                  |
| -------------------------- | ---- | ------------------------- |
| FitNet                     | 2015 | 中间层特征直接做 MSE 回归 |
| AT (Attention Transfer)    | 2017 | 蒸馏注意力图而非原始特征  |
| SP (Similarity-Preserving) | 2019 | 保持样本间的相似性矩阵    |
| OFD (Overhaul)             | 2019 | 蒸馏经过特定变换后的特征  |

### 5.6 关系蒸馏（Relation-based Distillation）

蒸馏样本之间的关系结构，而非单个样本的特征。

```
关系蒸馏（RKD）：

样本三元组 (x_i, x_j, x_k)：
  Teacher:  → f_t(x_i), f_t(x_j), f_t(x_k)
  Student:  → f_s(x_i), f_s(x_j), f_s(x_k)

损失函数：
  L_RKD = || d_t(i,j) - d_s(i,j) ||²    （距离关系）
        + || θ_t(i,j,k) - θ_s(i,j,k) ||²  （角度关系）
```

## 六、温度 T 的作用与调参

### 6.1 温度对分布的影响数学分析

给定 logits $z = [10, 5, 0]$（3 分类），不同温度下的 softmax：

```
T=1  (标准)：
  p = [exp(10/1), exp(5/1), exp(0/1)] / Z
    = [22026,  148,   1] / 22175
    = [0.9933, 0.0067, 0.0000]
  → 几乎 one-hot，信息丢失

T=5  (高温)：
  p = [exp(2.0), exp(1.0), exp(0.0)] / Z
    = [7.389,  2.718,  1.000] / 11.107
    = [0.665,  0.245,  0.090]
  → 相对关系保留："类别0 > 类别1 > 类别2"

T=20 (极高)：
  p = [exp(0.5), exp(0.25), exp(0.0)] / Z
    = [1.649,  1.284,  1.000] / 3.933
    = [0.419,  0.326,  0.254]
  → 太均匀，信噪比下降
```

### 6.2 T 和 α 的联动效应

```
高温 T (10-20)：
  - Teacher 分布很平滑，负类信息丰富
  - 需要配合高 α (0.7-0.9) 强调蒸馏损失
  - 适合：Teacher 能力远强于 Student

中温 T (3-5)：
  - 平衡负类信息和类别区分度
  - α 在 0.5-0.7 左右
  - 适合：大多数蒸馏场景

低温 T (1-2)：
  - 接近标准交叉熵
  - α 可以更低 (0.1-0.3)
  - 适合：Student 容量接近 Teacher
```

## 七、代码实现（PyTorch）

### 7.1 蒸馏训练核心函数

```python
import torch
import torch.nn as nn
import torch.nn.functional as F


def kl_divergence_with_temperature(
    student_logits: torch.Tensor,
    teacher_logits: torch.Tensor,
    temperature: float = 4.0,
) -> torch.Tensor:
    """
    带温度的 KL 散度蒸馏损失。

    Args:
        student_logits: Student 模型输出 logits, shape (N, C)
        teacher_logits: Teacher 模型输出 logits, shape (N, C)
        temperature: 软化温度 T
    Returns:
        标量损失值
    """
    # log_softmax(student / T)  --- 概率的对数
    log_probs_s = F.log_softmax(student_logits / temperature, dim=-1)
    # softmax(teacher / T)  --- Target 概率
    probs_t = F.softmax(teacher_logits / temperature, dim=-1)

    # KL(P_t || P_s)
    loss = F.kl_div(log_probs_s, probs_t, reduction="batchmean")

    # 乘以 T^2 补偿梯度尺度
    loss = loss * (temperature ** 2)

    return loss


def distillation_loss(
    student_logits: torch.Tensor,
    teacher_logits: torch.Tensor,
    labels: torch.Tensor,
    temperature: float = 4.0,
    alpha: float = 0.7,
) -> torch.Tensor:
    """
    蒸馏总损失。

    L = α · T² · KL(P_t || P_s) + (1-α) · CE(student, y)

    Args:
        student_logits: Student logits, (N, C)
        teacher_logits: Teacher logits, (N, C)
        labels: 真实标签, (N,)
        temperature: 蒸馏温度
        alpha: 蒸馏损失权重
    Returns:
        总损失
    """
    kd_loss = kl_divergence_with_temperature(
        student_logits, teacher_logits, temperature
    )
    ce_loss = F.cross_entropy(student_logits, labels)

    total_loss = alpha * kd_loss + (1 - alpha) * ce_loss
    return total_loss
```

### 7.2 完整的蒸馏训练脚本骨架

```python
import torch
from torch.utils.data import DataLoader
from tqdm import tqdm


def distill_one_epoch(
    student: nn.Module,
    teacher: nn.Module,
    dataloader: DataLoader,
    optimizer: torch.optim.Optimizer,
    temperature: float,
    alpha: float,
    device: torch.device,
) -> float:
    """执行一个 epoch 的蒸馏训练。"""
    student.train()
    teacher.eval()  # Teacher 冻结

    total_loss = 0.0
    num_batches = 0

    for inputs, labels in tqdm(dataloader, desc="Distilling"):
        inputs, labels = inputs.to(device), labels.to(device)

        optimizer.zero_grad()

        # Teacher 推理（无梯度）
        with torch.no_grad():
            teacher_logits = teacher(inputs)

        # Student 推理
        student_logits = student(inputs)

        # 计算蒸馏损失
        loss = distillation_loss(
            student_logits=student_logits,
            teacher_logits=teacher_logits,
            labels=labels,
            temperature=temperature,
            alpha=alpha,
        )

        loss.backward()
        optimizer.step()

        total_loss += loss.item()
        num_batches += 1

    return total_loss / num_batches


def evaluate(
    model: nn.Module,
    dataloader: DataLoader,
    device: torch.device,
) -> dict:
    """评估模型准确率。"""
    model.eval()
    correct = 0
    total = 0
    loss = 0.0
    criterion = nn.CrossEntropyLoss()

    with torch.no_grad():
        for inputs, labels in dataloader:
            inputs, labels = inputs.to(device), labels.to(device)
            outputs = model(inputs)
            loss += criterion(outputs, labels).item()
            _, predicted = outputs.max(1)
            total += labels.size(0)
            correct += predicted.eq(labels).sum().item()

    return {
        "acc": 100.0 * correct / total,
        "loss": loss / len(dataloader),
        "correct": correct,
        "total": total,
    }
```

### 7.3 特征蒸馏示例（Attention Transfer）

```python
class AttentionTransferLoss(nn.Module):
    """
    注意力迁移损失（Attention Transfer, Zagoruyko 2017）。
    蒸馏 Teacher 和 Student 中间层的注意力图。

    注意力图定义：对特征图按通道求平方和 → 空间注意力
        A(F) = sum_{c} F_c²  其中 F ∈ R^{C×H×W}
    """

    def __init__(self, p: int = 2):
        super().__init__()
        self.p = p  # 使用 L2 范数

    def attention_map(self, features: torch.Tensor) -> torch.Tensor:
        """从特征图生成空间注意力图。"""
        # features: (N, C, H, W)
        return torch.sum(features ** 2, dim=1)  # (N, H, W)

    def forward(
        self,
        student_features: torch.Tensor,
        teacher_features: torch.Tensor,
    ) -> torch.Tensor:
        """
        计算注意力图之间的损失。

        L_AT = || A_s / ||A_s||₂ - A_t / ||A_t||₂ ||₂
        """
        att_s = self.attention_map(student_features)
        att_t = self.attention_map(teacher_features)

        # L2 归一化
        att_s = att_s / att_s.view(att_s.size(0), -1).norm(dim=-1, keepdim=True)
        att_t = att_t / att_t.view(att_t.size(0), -1).norm(dim=-1, keepdim=True)

        return F.mse_loss(att_s, att_t)


# ========== 使用示例 ==========

class StudentWithIntermediate(nn.Module):
    """返回中间特征和最终 logits 的 Student。"""
    def __init__(self):
        super().__init__()
        self.backbone = ...    # 主干网络
        self.classifier = ...  # 分类头

    def forward(self, x):
        features = self.backbone(x)  # (N, C, H, W)
        logits = self.classifier(features.flatten(1))
        return logits, features


def feature_distillation_loss(
    student_logits, teacher_logits,
    student_features, teacher_features,
    labels, T, alpha, beta,
):
    """日志蒸馏 + 特征蒸馏联合损失。"""
    # Logits 蒸馏
    kd_loss = kl_divergence_with_temperature(student_logits, teacher_logits, T)
    ce_loss = F.cross_entropy(student_logits, labels)

    # 特征蒸馏（Attention Transfer）
    at_loss = AttentionTransferLoss()(student_features, teacher_features)

    # 总损失
    total = alpha * (T ** 2) * kd_loss \
          + (1 - alpha) * ce_loss \
          + beta * at_loss

    return total
```

## 八、知识蒸馏的应用场景与局限

### 8.1 适用场景

```
┌──────────────────────────────────────────────────────────────┐
│                     适用性对比                                │
├──────────────────────┬───────────────────────────────────────┤
│ ✅ 强烈推荐            │ ❌ 不太适用                           │
├──────────────────────┼───────────────────────────────────────┤
│ 移动端/边缘设备部署    │ Teacher 本身已经很小 (< 1M params)    │
│ 实时推理场景           │ 数据集标注质量极差                    │
│ 模型 Ensemble 压缩     │ 任务非常简单（层次结构不明显）         │
│ 隐私保护（不泄露数据）  │ Teacher 能力本身就不足               │
│ 跨架构知识迁移         │ 需要严格保真度（医疗诊断）            │
│ (CNN → Transformer)   │                                       │
└──────────────────────┴───────────────────────────────────────┘
```

### 8.2 局限性

1. **容量差距问题**：当 Teacher 和 Student 容量差距过大时，蒸馏效果会下降 —— Student 无法模仿 Teacher 的分布
2. **Teacher 偏差继承**：如果 Teacher 本身有偏差（数据集偏差、过拟合），Student 也会学到这些偏差
3. **计算开销翻倍**：训练时需要同时运行 Teacher 和 Student，显存和算力需求不低于直接训练大模型
4. **调参敏感**：$T$ 和 $\alpha$ 相互影响，不同数据集和架构的最优配置差异大

## 附录：常用评估指标

```
蒸馏效果的核心评估：

1. 精度指标
   ΔAcc = Acc_distilled - Acc_scratch    ← 蒸馏带来的绝对提升
   Retention = Acc_distilled / Acc_teacher × 100%  ← 保留率

2. 效率指标
   Compression = params_teacher / params_student     ← 压缩比
   Speedup = latency_teacher / latency_student       ← 加速比

3. 综合指标
   Efficiency_Score = ΔAcc × log(Compression)       ← 蒸馏效率
```
